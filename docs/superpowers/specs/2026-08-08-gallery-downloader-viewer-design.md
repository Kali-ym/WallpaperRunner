# 套图下载器与本地查看器 — 设计规格

日期：2026-08-08  
状态：待用户审阅

## 1. 目标

构建一个 **Electron 桌面应用**，支持：

1. 根据套图 URL 批量排队下载整套原图与元信息  
2. 在本地浏览已下载套图（搜索、缩略图、全屏键盘翻图）  
3. 将爬取功能集成进查看器  
4. 通过 **来源适配器** 扩展新站点，首版只实现 xChina

首版目标站点示例：

- `https://xchina.co/photo/id-63c799bf45baf.html`
- 分页：`.../1.html`、`.../2.html` …

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 形态 | Electron 桌面窗口 |
| UI | React |
| 爬取 | Node 主进程 + HTML 解析（axios/fetch + cheerio） |
| 队列 | 支持多 URL |
| 目录命名 | `{source}_{id}_{标题}`（含来源前缀，避免跨站 ID 冲突） |
| 元数据 | 标题、ID、来源 URL、模特/作者、标签、页数、封面、图片列表 |
| 查看器 | 库列表 + 搜索筛选 + 缩略图 + 全屏 + 键盘 + 下载进度面板 |
| 扩展 | Source Adapter 接口；预留 Playwright 适配位但不首版引入 |

## 3. 整体架构

```
┌─────────────────────────────────────────┐
│  Renderer (React)                       │
│  库列表 / 搜索 / 大图浏览 / 下载面板 / 设置 │
└─────────────────┬───────────────────────┘
                  │ IPC
┌─────────────────▼───────────────────────┐
│  Main (Node)                            │
│  队列调度 · 适配器注册表 · 下载器 · 库索引  │
└─────────────────┬───────────────────────┘
                  │
┌─────────────────▼───────────────────────┐
│  Local FS                               │
│  {root}/{source}_{id}_{title}/001.jpg … │
│  metadata.json · library 索引           │
└─────────────────────────────────────────┘
```

- **渲染进程**：只做 UI 与用户交互；不直接发爬取请求。  
- **主进程**：解析、下载、写盘、维护索引；通过 IPC 推送进度与结果。  
- **存储**：用户可配置下载根目录（默认如 `~/Pictures/gallery-library`）。

## 4. 来源适配器（多站点入口）

爬虫逻辑不绑死单一域名。统一接口（概念形状）：

```ts
interface SourceAdapter {
  id: string;          // e.g. "xchina"
  name: string;        // 展示名
  match(url: string): boolean;
  parseGallery(url: string, ctx: ParseContext): Promise<GalleryParseResult>;
  // 可选：默认请求头、限速、原图校验策略
}
```

`GalleryParseResult` 至少包含：

- `source`、`galleryId`、`title`、`sourceUrl`
- `author` / `model`（可空）
- `tags: string[]`
- `pageCount`
- `coverUrl`（可空）
- `images: { index: number; url: string }[]`（全部分页合并后的有序原图列表）

**调度：**

1. 用户提交 URL（一条或多条）  
2. 注册表中按顺序 `match(url)`  
3. 命中则调用该适配器 `parseGallery`  
4. 结果进入统一下载管道与本地库格式  
5. 无命中 → 任务失败，提示「暂不支持该来源」

**首版：** 仅注册 `xchina` 适配器。  
**加新站：** 新增适配器文件并注册即可，不必改查看器与队列核心。  
`metadata.json` 必须包含 `source` 字段以区分来源。

## 5. xChina 爬取流程

1. 归一化 URL，提取套图 ID（如 `63c799bf45baf`）；带页码的 URL 仍按整套处理。  
2. 请求第 1 页，解析标题、模特/作者、标签、分页总数、封面候选。  
3. 按 `https://xchina.co/photo/id-{id}/{n}.html` 抓取全部页。  
4. 收集套图图片节点，**跳过广告块**。  
5. 解析到**原图 URL**（优先大图链接、`data-src`、或站点已知的 thumb→original 路径规则）；下载时用 `Content-Type` / 体积等启发式避免明显缩略图。  
6. 按顺序保存为 `001`、`002`…（保留真实扩展名）。  
7. 写入 `metadata.json`，更新 `library` 索引。  
8. UI 可立即搜索与浏览。

### 队列与并发

- 多 URL 进入下载队列。  
- 默认：**套图之间串行**；**套内图片有限并发**（可在设置中配置）。  
- 支持暂停 / 取消单项。  
- 进度经 IPC 推送到下载面板（状态、页进度、张进度）。

### 失败与重试

- 单页 / 单图：有限次重试（含超时、403/429 的指数退避）。  
- 单图最终失败：记录序号，其余继续。  
- 任务级失败不阻断队列中其他套图。  
- 同 ID 目录已存在：默认跳过；可选手动「重新下载 / 覆盖」。  
- 磁盘满 / 无写权限：停止当前任务并明确提示。

## 6. 本地存储布局

```
{downloadRoot}/
  library.json                      # 轻量索引，加速列表与搜索
  xchina_63c799bf45baf_咬一口兔兔/
    metadata.json
    cover.jpg                       # 可选，或由第一张图兼任
    001.jpg
    002.jpg
    ...
```

唯一键为 `(source, galleryId)`；文件夹名在用户所选「ID + 标题」基础上增加 `source_` 前缀。

`metadata.json` 字段（权威元数据）：

- `source`、`galleryId`、`title`、`sourceUrl`
- `author`（模特/作者，站点无则空字符串）
- `tags`、`pageCount`
- `cover`（相对路径）
- `images`（相对路径有序列表）
- `downloadedAt`

索引损坏时，支持「从磁盘扫描各套图 `metadata.json` 重建索引」。

## 7. 查看器与 UI

### 套图库

- 展示封面、标题、标签、图片数  
- 按标题 / 标签 / 模特关键词搜索筛选  
- 点击进入缩略图网格  

### 浏览

- 大图模式：上一张 / 下一张  
- 快捷键：`←` / `→`，`Esc` 退出，`F` 全屏  
- 一律读取本地文件，不回源站  

### 下载面板（集成爬取）

- 粘贴单条或多条 URL（换行或逗号分隔）  
- 队列列表：等待 / 解析中 / 下载中 / 完成 / 失败  
- 显示页、张进度与错误摘要  
- 完成后出现在库中，可一键打开  

### 设置

- 下载根目录  
- 套内图片并发数  
- 下载完成后是否自动打开该套图  

## 8. 首版明确不做

- 网站账号登录与站内收藏同步  
- Playwright / 无头浏览器（仅架构上预留替换解析实现的空间）  
- 云同步、多用户  
- 非图片媒体（视频）  

## 9. 验收标准

1. 粘贴 `https://xchina.co/photo/id-63c799bf45baf.html`，能自动翻完全部分页并下载完整套图。  
2. 保存的是原图而非缩略图；广告图不入库。  
3. 文件夹名为 `{source}_{id}_{标题}`，图片为有序编号。  
4. 可一次提交多个 URL；队列有进度；单项失败不拖垮整队。  
5. 库内可按标题/标签搜索；支持缩略图 + 全屏键盘翻图。  
6. 断网或单图失败时有可见错误信息，应用不崩溃。  
7. 未知来源 URL 提示「暂不支持」；适配器注册表可扩展新来源而无需改动库浏览核心。  

## 10. 风险与应对

| 风险 | 应对 |
| --- | --- |
| 站点改版导致选择器失效 | 适配器内集中维护解析规则；失败日志便于热修 |
| 反爬 / 限流 | 限速、重试退避；必要时日后换 Playwright 实现同一接口 |
| 原图 URL 规则变更 | 多层候选（链接 → 属性 → 路径变换）+ 下载校验 |
| 标题含非法路径字符 | 文件名消毒（替换 `\/:*?"<>|` 等） |

## 11. 实现备注

- 技术栈：Electron + React + TypeScript（推荐）  
- 主进程模块划分建议：`adapters/`、`queue/`、`downloader/`、`library/`、`ipc/`  
- 渲染进程路由建议：库首页、套图详情、下载中心、设置
