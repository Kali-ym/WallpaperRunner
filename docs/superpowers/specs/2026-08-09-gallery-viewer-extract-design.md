# 套图内解压 + 查看器升级 — 设计规格

日期：2026-08-09  
状态：待用户审阅  
相关：UX 大升级、zip/7z/rar 解压、图库套图页

## 1. 目标

1. 压缩包解压入口从「库卡片」挪到「套图内部」；多压缩包解压时图片文件名序号续编、互不覆盖  
2. 套图页交互收敛到右键菜单；压缩包缩略图仅显示压缩包图标  
3. 图片查看器改用 Yet Another React Lightbox（YARL）

## 2. 决策摘要

| 项 | 选择 |
| --- | --- |
| 库列表解压 | 移除 |
| 解压入口 | 套图内：压缩包右键 / 选中后解压 |
| 多包命名 | 按当前套图已有图片最大序号续编（001…） |
| 套图改名 | 解压不新建套图、不改 galleryId / 显示名 |
| 压缩包缩略图 | 仅图标，不做内容预览 |
| 查看器 | Yet Another React Lightbox + Zoom / Thumbnails / Counter / Fullscreen |

## 3. 压缩包与文件模型

- 套图 `metadata.images` 可同时含图片与压缩包路径（`.zip` / `.7z` / `.rar`）  
- 下载完成弹窗仍可解压到**当前套图**（`intoExisting`）  
- 库卡片右键菜单**不再**提供「解压压缩包」

### 3.1 序号续编（防覆盖）

解压写入文件时：

1. 扫描当前套图目录中已有图片文件名 `NNN.ext` 的最大序号 `N`  
2. 新解出的图片从 `N+1` 起编号：`041.jpg`、`042.png`…  
3. 多压缩包依次解压时，每一包都基于**当时**已有最大序号续编，因此不会互相覆盖

不要求按压缩包分子目录；统一扁平进当前套图目录。

### 3.2 套图内 UI

- **图片卡**：缩略图；右键：设封面、删除  
- **压缩包卡**：固定压缩包图标 + 文件名；右键：解压、删除  
- 多选：顶栏仅保留必要批量操作（如删除所选、解压所选压缩包）；其余以右键为主  
- 点图片 → 打开 YARL；点压缩包 → 不进查看器（可直接触发解压或仅选中，默认右键解压为主）

## 4. 套图页结构

- 顶栏：返回、标题、收藏；次要操作进溢出或右键  
- 网格混排图片与压缩包，视觉区分清晰  
- 解压弹窗：密码、解压后是否删除压缩包（沿用现有 ExtractZipModal）

## 5. 图片查看器（YARL）

替换自研 `Lightbox.tsx`（可删除或薄封装）：

- 依赖：`yet-another-react-lightbox`  
- 插件：`Zoom`、`Thumbnails`、`Counter`、`Fullscreen`  
- 幻灯片仅包含图片 URL（过滤压缩包）  
- 键盘：左右切图、Esc 关闭（库默认行为）

## 6. 范围外

- rar/7z 分卷包、自定义解压目标目录  
- 视频在查看器内播放（可后续加 YARL Video 插件）

## 7. 验收

- [ ] 库右键无「解压压缩包」  
- [ ] 套图内压缩包显示图标；右键可解压/删除  
- [ ] 连续解压两个压缩包，图片序号不冲突、文件不覆盖  
- [ ] 图片点击进入 YARL，可缩放、缩略图条、计数、全屏  
- [ ] 压缩包不可进入 YARL
